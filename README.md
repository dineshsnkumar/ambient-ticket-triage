### Ambient Ticket Triage

An agentic ticketing application for IT helpdesk that runs in the background to categorize, prioritize and to sends automated emails

#### Package Installation

This projects uses langchain, langgraph and langsimth frameworks. It uses Gemini as LLM. Before installing the packages, make sure you have the API Keys for `GEMINI_API_KEY` and `LANGSMITH_API_KEY`

- To install the packages, please run `uv pip install -r requirements.txt`
